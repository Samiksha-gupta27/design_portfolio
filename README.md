# design_portfolio

A personal portfolio site for showcasing design projects, creative work, and contact information. Built with HTML, CSS, and a touch of JavaScript — includes dark mode toggle, gradient hero section, and a smooth call-to-action button.

---

## 🌟 Features

- Responsive layout for all screen sizes
- Light/Dark mode toggle (with cute sun/moon switch!)
- Modern gradient hero section
- Interactive call-to-action button with hover effect
- Clean navigation bar with anchor links
